## 二、为什么 PrepWise 是 AI PM 的黄金素材

PrepWise 让候选人在面试中同时证明三件**AI PM 最稀缺**的事：

```
┌─────────────────────────────────────────────────────────┐
│  ① 懂 AI   →  prompt 工程 / 流式 / 多模型适配 / 成本权衡 │
│  ② 懂产品  →  痛点洞察 / 闭环设计 / 数据驱动 / 体验打磨  │
│  ③ 能落地  →  独立 0-1 全链路交付 + 上线部署             │
└─────────────────────────────────────────────────────────┘
```

> 面试官的潜台词：「这个 PM 不是只画原型、只会说『让 AI 帮我做』，而是真的把 AI 能力产品化并交付了。」这就是差异化。

## 四、阅读与备战节奏建议

**半天速成版（推荐先用这个）**：
1. 读 `01` 的「简历可贴版」，把简历改好投出去。
2. 读 `02` 的 **维度 A（产品定位）+ 维度 B（AI 产品设计）**，这两块是 AI PM 面试必考核心。
3. 读 `03` 的「投递自检表」，确认简历命中 JD 高频词。

**1-2 天冲刺版**：
- 上述全部 + 完整刷 `02` 七大维度 + 背熟 `01` 的 STAR 详讲版 + 准备 `03` 的 3 个反问。

**一周精修版**：
- 把 `02` 每道题的「连环追问」当成独立题再练一遍，确保被深挖时不露馅；同时跑一遍项目（`npm run dev`）熟悉每个功能的实际交互，做到「讲得出，也演示得了」。

## 五、重要使用提醒（避坑）

- **数据要诚实**：素材中的数字（如「适配 12+ 模型」「9 套模板」）均来自项目真实情况，可演示验证。**不要**临时编造「提升了 XX%」之类无法核实的指标——面试官一追问就破。
- **讲产品而非讲代码**：AI PM 面试不需要背 Vue 源码。被问技术细节时，用「**我这样设计是因为……**」（产品决策）而非「**我用 xxx 库实现了……**」（实现细节）来回答。
- **界定边界**：诚实区分「我独立完成的」vs「站在开源/工具肩膀上的」。PrepWise 大量复用了成熟开源库（three-vrm / pdfjs / tesseract），这是工程判断，不是减分项，但要说清楚。
